# StudyForge AI

StudyForge AI is a small student project for making studying a little easier.

### What it includes
- AI-style chat for simple study questions
- a basic study planner
- a PDF notes section
- a small presentation section

### Tech used
- React
- Vite
- Tailwind CSS
- JavaScript

### Run locally
npm install
npm run dev

This is a learning project and I am still improving the features.
